# 슈퍼도장 설계 문서

전자 서명과 도장 이미지를 브라우저에서 만들고 PNG로 바로 내려받는 웹서비스입니다.

## 1. 목표와 범위

| 기능 | 설명 |
| --- | --- |
| 직접 서명 | 손가락, 마우스, 펜으로 서명을 그리고 PNG로 저장 |
| 서명 생성 | 이름을 입력하면 손글씨 글꼴 여러 개로 서명 후보를 만들고, 고른 것을 PNG로 저장 |
| 도장 생성 | 이름을 입력하면 모양과 글꼴을 조합한 도장 후보를 만들고, 고른 것을 PNG로 저장 |
| 저장 옵션 | 배경 투명 또는 배경색 선택, 잉크 색 선택, 해상도 선택 |
| 언어 | 한글, 영문 (입력값에서 자동 감지하고 직접 바꿀 수도 있음) |
| 바로 다운로드 | 후보 카드마다 다운로드 버튼, 선택한 항목은 하단 큰 버튼으로 저장. 지원 브라우저에서는 클립보드 복사도 제공 |

범위 밖: 회원가입, 서버 보관, 전자계약 연동, 공인 인증. 만든 이미지는 서버로 전송하지 않습니다.

## 2. 기술 선택

- **정적 웹앱**: HTML, CSS, 바닐라 JavaScript(ES 모듈). 빌드 도구와 런타임 의존성이 없습니다.
- **렌더링**: Canvas 2D. 모든 이미지는 사용자 브라우저에서 그립니다.
- **글꼴**: Google Fonts CDN. 한글 글꼴은 글자 범위별로 나뉘어 있어서(unicode-range) 입력한 글자에 필요한 조각만 받습니다. 그리기 전에 `document.fonts.load()`로 해당 글꼴과 글자를 미리 불러옵니다.
- **배포**: 아무 정적 호스팅(GitHub Pages, Netlify, S3 등)에 폴더 그대로 올리면 됩니다. ES 모듈을 쓰므로 `file://`로 직접 열지 말고 HTTP로 서비스해야 합니다.

## 3. 화면 구성

모바일 우선 한 화면 구성입니다.

```
┌──────────────────────────────┐
│ 헤더: 슈퍼도장 로고            │
├──────────────────────────────┤
│ [직접 서명] [서명 생성] [도장 생성] │  ← 탭
├──────────────────────────────┤
│ 탭별 입력 영역                 │
│  - 직접 서명: 그리기 패드, 펜 굵기, 되돌리기, 지우기 │
│  - 서명/도장 생성: 언어 선택, 이름 입력(최대 14자), 스타일 옵션 │
│ 후보 카드 그리드 (선택 + 카드별 다운로드) │
├──────────────────────────────┤
│ 저장 옵션: 잉크 색 / 배경(투명·흰색·사용자 색) / 해상도 │
│ 미리보기(투명 배경은 체크무늬)  │
│ [PNG 다운로드]  [복사]          │
└──────────────────────────────┘
```

## 4. 모듈 구조

```
index.html
css/style.css
js/
  app.js              탭 전환, 상태 관리, 이벤트 연결
  fonts.js            글꼴 목록과 로더
  signature-pad.js    그리기 패드 (획 데이터 저장, 다시 그리기)
  signature-gen.js    이름 → 서명 이미지
  stamp-gen.js        이름 → 도장 이미지
  exporter.js         여백 자르기, 배경 합성, PNG 저장/복사
  core/
    text.js           언어 감지, 입력 검증, 파일 이름 만들기 (DOM 없음)
    geometry.js       도장 글자 배치 계산 (DOM 없음)
    random.js         시드 고정 난수 (인주 질감용)
tests/                Node 내장 테스트 러너로 core 모듈 검사
scripts/serve.mjs     의존성 없는 로컬 정적 서버
```

`core/`는 DOM을 쓰지 않아서 Node에서 바로 테스트합니다.

## 5. 데이터 흐름

모든 결과물은 "렌더러 함수 + 옵션" 형태로 다룹니다.

```
item = { kind: 'signature' | 'stamp' | 'drawing', render(scale, ink) → Canvas, label }
```

- 후보 카드 미리보기는 `render(1)`로 그립니다.
- 다운로드할 때는 선택한 해상도 배율로 `render(scale)`을 다시 호출합니다. 비트맵을 늘리지 않고 벡터처럼 다시 그리므로 고해상도에서도 선이 깨지지 않습니다.
- 직접 서명도 픽셀이 아니라 획 좌표(x, y, 굵기)를 저장해 두었다가 배율에 맞춰 다시 그립니다.

내보내기 순서:

1. `render(scale, ink)`로 투명 캔버스를 얻습니다.
2. 서명류는 알파값이 있는 영역만 남기고 여백을 자른 뒤 일정한 여백을 붙입니다.
3. 배경이 투명이면 그대로, 색이 있으면 새 캔버스에 배경을 칠하고 위에 그립니다.
4. `canvas.toBlob('image/png')` → 객체 URL → `<a download>` 클릭으로 저장합니다.
5. 파일 이름: `서명_홍길동_20261117.png`, `도장_홍길동_20261117.png`처럼 종류, 이름, 날짜로 만듭니다. 파일 이름에 쓸 수 없는 문자는 제거합니다.

## 6. 직접 서명 패드

- Pointer Events로 마우스, 터치, 펜을 한 번에 처리합니다. 패드에 `touch-action: none`을 걸어 그리는 동안 화면이 스크롤되지 않게 합니다.
- 굵기: 기본 굵기에 속도를 반영합니다. 빠르게 그으면 얇아지고 천천히 그으면 두꺼워집니다. 펜 필압(pressure)이 들어오면 함께 반영합니다.
- 부드럽게 그리기: 점 사이 중간점을 이어 2차 곡선으로 그립니다.
- 되돌리기(획 단위), 전체 지우기를 제공합니다.
- 화면 회전이나 크기 변경 시 저장된 획을 새 크기에 맞춰 다시 그립니다.

## 7. 서명 생성

- 언어 자동 감지: 입력에 한글 음절이나 자모가 있으면 한글, 없으면 영문 글꼴 묶음을 씁니다. 사용자가 직접 고르면 그 선택을 따릅니다.
- 영문 모드에서 한글을 입력하면 영문 글꼴에 한글 글자가 없으므로 안내 메시지를 띄웁니다.
- 글꼴 묶음
  - 한글: Nanum Pen Script, Nanum Brush Script, East Sea Dokdo, Dokdo, Gaegu, Hi Melody, Gamja Flower, Yeon Sung
  - 영문: Great Vibes, Dancing Script, Allura, Sacramento, Alex Brush, Mr Dafoe, Homemade Apple, Caveat
- 스타일 옵션: 기울기(0~20도), 밑줄 장식(끝을 날린 곡선) 켜기/끄기
- 크기 맞추기: 글자를 큰 크기로 측정한 뒤(`measureText`의 실제 경계 상자) 정해진 높이에 맞게 비율을 정합니다. 기울기를 주면 늘어난 폭까지 계산해 잘리지 않게 합니다.

## 8. 도장 생성

### 8.1 모양과 배치

| 변형 | 모양 | 배치 |
| --- | --- | --- |
| 타원 세로 | 세로로 긴 타원 | 한 줄 세로쓰기 (4자 초과면 2열) |
| 원형 | 원 | 2×2 또는 자동 격자 |
| 정사각 | 사각 테두리 | 2×2 (3자 이름은 "인"을 붙여 4자) |
| 둥근 사각 | 모서리가 둥근 사각 | 2×2 또는 자동 격자 |
| 이중 원 | 바깥 원 + 안쪽 원 | 원형과 같음 |
| 가로 직사각 | 가로 사각 | 한 줄 가로쓰기 (영문, 긴 이름) |

- **"인" 붙이기**: 켜면 이름 뒤에 "인"(영문은 붙이지 않음)을 붙입니다. 3자 이름이 4자가 되어 2×2에 꽉 찹니다.
- **읽는 순서**: 가로(왼쪽→오른쪽, 위→아래) 또는 전통 세로(오른쪽 열부터 위→아래).

### 8.2 글자 맞추기

1. 글자 수 n으로 격자(열×행)를 정합니다. 예: 1~4자 세로 타원은 1×n, 4자 사각은 2×2, 5~6자는 2×3, 7~9자는 3×3.
2. 모양 안에 들어가는 가장 큰 사각형을 구합니다. 반지름 a, b인 타원에서 격자 비율 r(열/행)에 맞는 내접 사각형은 tanθ = a / (b·r)일 때 폭 2a·cosθ, 높이 2b·sinθ입니다.
3. 칸마다 글자의 실제 경계 상자를 재고, 칸을 채우도록 가로와 세로 배율을 따로 정합니다. 도장 글씨처럼 꽉 차 보이게 하려는 목적이고, 글자가 지나치게 찌그러지지 않도록 가로세로 비율 차이를 0.6~1.6배로 제한합니다.

### 8.3 글꼴

- 한글: Nanum Myeongjo(ExtraBold), Song Myung, Gowun Batang(Bold), Hahmlet(Bold), Black Han Sans, Do Hyeon, Nanum Brush Script
- 영문: Cinzel, Playfair Display, Libre Baskerville, Oswald

전서체(옛 도장 서체)는 무료 웹폰트로 구하기 어려워 명조와 굵은 고딕 계열로 대신합니다.

### 8.4 인주 질감

선택 사항입니다. 켜면 시드를 고정한 난수로 작은 점을 지워 찍힌 도장처럼 보이게 합니다. 시드는 이름과 변형 번호로 정하므로 미리보기와 다운로드 결과가 같습니다.

## 9. 저장 옵션

| 옵션 | 값 |
| --- | --- |
| 잉크 색 | 서명: 검정(기본), 남색, 파랑, 사용자 색 / 도장: 빨강(기본), 주황빨강, 검정, 사용자 색 |
| 배경 | 투명(기본), 흰색, 사용자 색 |
| 해상도 | 보통(2배), 고해상도(4배) |

미리보기에서는 투명 배경을 체크무늬로 보여 줍니다.

## 10. 예외 처리

- 이름이 비었거나 14자를 넘으면 버튼을 막고 안내합니다.
- 글꼴을 3초 안에 불러오지 못하면 대체 글꼴로 그리고 해당 카드에 표시합니다.
- 클립보드 이미지 복사를 지원하지 않는 브라우저에서는 복사 버튼을 숨깁니다.
- 아무것도 그리지 않은 패드에서 저장을 누르면 안내합니다.

## 11. 접근성

- 탭은 `role="tablist"`와 방향키 이동을 지원합니다.
- 후보 카드는 버튼으로 만들어 키보드로 고를 수 있고, 선택 상태를 `aria-pressed`로 알립니다.
- 상태 메시지는 `aria-live` 영역으로 읽어 줍니다.

## 12. 테스트

- `node --test`: 언어 감지, 입력 검증, 파일 이름, 격자 계산, 내접 사각형 계산, 시드 난수 재현성
- 브라우저 확인: Playwright로 세 탭에서 생성과 다운로드가 되는지, 투명 PNG의 모서리 알파값이 0인지 확인합니다.
