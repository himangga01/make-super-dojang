# 슈퍼도장 설계 문서

> 2판: 서명 형태 48가지(한글·영문 각 24), 도장 28가지, 추가 기능 6가지를 더했습니다. 바뀐 내용은 13장 이후에 정리했고, 1~12장은 1판 설계입니다.

전자 서명과 도장 이미지를 브라우저에서 만들고 PNG로 바로 내려받는 웹서비스입니다.

## 1. 목표와 범위

| 기능 | 설명 |
| --- | --- |
| 직접 서명 | 손가락, 마우스, 펜으로 서명을 그리고 PNG로 저장 |
| 서명 생성 | 이름을 입력하면 손글씨 글꼴 여러 개로 서명 후보를 만들고, 고른 것을 PNG로 저장 |
| 도장 생성 | 이름을 입력하면 모양과 글꼴을 조합한 도장 후보를 만들고, 고른 것을 PNG로 저장 |
| 저장 옵션 | 배경 투명 또는 배경색 선택, 잉크 색 선택, 해상도 선택 |
| 언어 | 한글, 영문 (입력값에서 자동 감지하고 직접 바꿀 수도 있음) |
| 바로 다운로드 | 후보 카드마다 다운로드 버튼, 선택한 항목은 하단 큰 버튼으로 저장. 지원 브라우저에서는 클립보드 복사도 제공 |

범위 밖: 회원가입, 서버 보관, 전자계약 연동, 공인 인증. 만든 이미지는 서버로 전송하지 않습니다.

## 2. 기술 선택

- **정적 웹앱**: HTML, CSS, 바닐라 JavaScript(ES 모듈). 빌드 도구와 런타임 의존성이 없습니다.
- **렌더링**: Canvas 2D. 모든 이미지는 사용자 브라우저에서 그립니다.
- **글꼴**: Google Fonts CDN. 한글 글꼴은 글자 범위별로 나뉘어 있어서(unicode-range) 입력한 글자에 필요한 조각만 받습니다. 그리기 전에 `document.fonts.load()`로 해당 글꼴과 글자를 미리 불러옵니다.
- **배포**: 아무 정적 호스팅(GitHub Pages, Netlify, S3 등)에 폴더 그대로 올리면 됩니다. ES 모듈을 쓰므로 `file://`로 직접 열지 말고 HTTP로 서비스해야 합니다.

## 4. 모듈 구조

```
index.html
css/style.css
js/
  app.js              탭 전환, 상태 관리, 이벤트 연결
  fonts.js            글꼴 목록과 로더
  signature-pad.js    그리기 패드 (획 데이터 저장, 다시 그리기)
  signature-gen.js    이름 → 서명 이미지
  stamp-gen.js        이름 → 도장 이미지
  exporter.js         여백 자르기, 배경 합성, PNG 저장/복사
  core/
    text.js           언어 감지, 입력 검증, 파일 이름 만들기 (DOM 없음)
    geometry.js       도장 글자 배치 계산 (DOM 없음)
    random.js         시드 고정 난수 (인주 질감용)
tests/                Node 내장 테스트 러너로 core 모듈 검사
scripts/serve.mjs     의존성 없는 로컬 정적 서버
```

`core/`는 DOM을 쓰지 않아서 Node에서 바로 테스트합니다.

## 5. 데이터 흐름

모든 결과물은 "렌더러 함수 + 옵션" 형태로 다룹니다.

```
item = { kind: 'signature' | 'stamp' | 'drawing', render(scale, ink) → Canvas, label }
```

- 후보 카드 미리보기는 `render(1)`로 그립니다.
- 다운로드할 때는 선택한 해상도 배율로 `render(scale)`을 다시 호출합니다. 비트맵을 늘리지 않고 벡터처럼 다시 그리므로 고해상도에서도 선이 깨지지 않습니다.
- 직접 서명도 픽셀이 아니라 획 좌표(x, y, 굵기)를 저장해 두었다가 배율에 맞춰 다시 그립니다.

내보내기 순서:

1. `render(scale, ink)`로 투명 캔버스를 얻습니다.
2. 서명류는 알파값이 있는 영역만 남기고 여백을 자른 뒤 일정한 여백을 붙입니다.
3. 배경이 투명이면 그대로, 색이 있으면 새 캔버스에 배경을 칠하고 위에 그립니다.
4. `canvas.toBlob('image/png')` → 객체 URL → `<a download>` 클릭으로 저장합니다.
5. 파일 이름: `서명_홍길동_20261117.png`, `도장_홍길동_20261117.png`처럼 종류, 이름, 날짜로 만듭니다. 파일 이름에 쓸 수 없는 문자는 제거합니다.

## 6. 직접 서명 패드

- Pointer Events로 마우스, 터치, 펜을 한 번에 처리합니다. 패드에 `touch-action: none`을 걸어 그리는 동안 화면이 스크롤되지 않게 합니다.
- 굵기: 기본 굵기에 속도를 반영합니다. 빠르게 그으면 얇아지고 천천히 그으면 두꺼워집니다. 펜 필압(pressure)이 들어오면 함께 반영합니다.
- 부드럽게 그리기: 점 사이 중간점을 이어 2차 곡선으로 그립니다.
- 되돌리기(획 단위), 전체 지우기를 제공합니다.
- 화면 회전이나 크기 변경 시 저장된 획을 새 크기에 맞춰 다시 그립니다.

## 7. 서명 생성

- 언어 자동 감지: 입력에 한글 음절이나 자모가 있으면 한글, 없으면 영문 글꼴 묶음을 씁니다. 사용자가 직접 고르면 그 선택을 따릅니다.
- 영문 모드에서 한글을 입력하면 영문 글꼴에 한글 글자가 없으므로 안내 메시지를 띄웁니다.
- 글꼴 묶음
  - 한글: Nanum Pen Script, Nanum Brush Script, East Sea Dokdo, Dokdo, Gaegu, Hi Melody, Gamja Flower, Yeon Sung
  - 영문: Great Vibes, Dancing Script, Allura, Sacramento, Alex Brush, Mr Dafoe, Homemade Apple, Caveat
- 스타일 옵션: 기울기(0~20도), 밑줄 장식(끝을 날린 곡선) 켜기/끄기
- 크기 맞추기: 글자를 큰 크기로 측정한 뒤(`measureText`의 실제 경계 상자) 정해진 높이에 맞게 비율을 정합니다. 기울기를 주면 늘어난 폭까지 계산해 잘리지 않게 합니다.

## 8. 도장 생성

### 8.1 모양과 배치

| 변형 | 모양 | 배치 |
| --- | --- | --- |
| 타원 세로 | 세로로 긴 타원 | 한 줄 세로쓰기 (4자 초과면 2열) |
| 원형 | 원 | 2×2 또는 자동 격자 |
| 정사각 | 사각 테두리 | 2×2 (3자 이름은 "인"을 붙여 4자) |
| 둥근 사각 | 모서리가 둥근 사각 | 2×2 또는 자동 격자 |
| 이중 원 | 바깥 원 + 안쪽 원 | 원형과 같음 |
| 가로 직사각 | 가로 사각 | 한 줄 가로쓰기 (영문, 긴 이름) |

- **"인" 붙이기**: 켜면 이름 뒤에 "인"(영문은 붙이지 않음)을 붙입니다. 3자 이름이 4자가 되어 2×2에 꽉 찹니다.
- **읽는 순서**: 가로(왼쪽→오른쪽, 위→아래) 또는 전통 세로(오른쪽 열부터 위→아래).

### 8.2 글자 맞추기

1. 글자 수 n으로 격자(열×행)를 정합니다. 예: 1~4자 세로 타원은 1×n, 4자 사각은 2×2, 5~6자는 2×3, 7~9자는 3×3.
2. 모양 안에 들어가는 가장 큰 사각형을 구합니다. 반지름 a, b인 타원에서 격자 비율 r(열/행)에 맞는 내접 사각형은 tanθ = a / (b·r)일 때 폭 2a·cosθ, 높이 2b·sinθ입니다.
3. 칸마다 글자의 실제 경계 상자를 재고, 칸을 채우도록 가로와 세로 배율을 따로 정합니다. 도장 글씨처럼 꽉 차 보이게 하려는 목적이고, 글자가 지나치게 찌그러지지 않도록 가로세로 비율 차이를 0.6~1.6배로 제한합니다.

### 8.3 글꼴

- 한글: Nanum Myeongjo(ExtraBold), Song Myung, Gowun Batang(Bold), Hahmlet(Bold), Black Han Sans, Do Hyeon, Nanum Brush Script
- 영문: Cinzel, Playfair Display, Libre Baskerville, Oswald

전서체(옛 도장 서체)는 무료 웹폰트로 구하기 어려워 명조와 굵은 고딕 계열로 대신합니다.

### 8.4 인주 질감

선택 사항입니다. 켜면 시드를 고정한 난수로 작은 점을 지워 찍힌 도장처럼 보이게 합니다. 시드는 이름과 변형 번호로 정하므로 미리보기와 다운로드 결과가 같습니다.

## 10. 예외 처리

- 이름이 비었거나 14자를 넘으면 버튼을 막고 안내합니다.
- 글꼴을 3초 안에 불러오지 못하면 대체 글꼴로 그리고 해당 카드에 표시합니다.
- 클립보드 이미지 복사를 지원하지 않는 브라우저에서는 복사 버튼을 숨깁니다.
- 아무것도 그리지 않은 패드에서 저장을 누르면 안내합니다.

## 11. 접근성

- 탭은 `role="tablist"`와 방향키 이동을 지원합니다.
- 후보 카드는 버튼으로 만들어 키보드로 고를 수 있고, 선택 상태를 `aria-pressed`로 알립니다.
- 상태 메시지는 `aria-live` 영역으로 읽어 줍니다.

## 12. 테스트

- `node --test`: 언어 감지, 입력 검증, 파일 이름, 격자 계산, 내접 사각형 계산, 시드 난수 재현성
- 브라우저 확인: Playwright로 세 탭에서 생성과 다운로드가 되는지, 투명 PNG의 모서리 알파값이 0인지 확인합니다.

## 14. 추가 기능 선정

전자서명·도장 이미지를 만드는 사람이 그다음에 하는 일을 기준으로 골랐습니다.

| 기능 | 해결하는 문제 | 구현 |
| --- | --- | --- |
| 사진에서 서명 가져오기 | 손글씨 서명을 화면에 그리면 평소 서명과 달라진다 | 종이 서명 사진의 배경을 지워 투명 PNG로 만든다 |

| 공유 | 휴대폰에서 메신저로 보내려면 저장 후 다시 찾아야 한다 | Web Share API (지원 기기에서만 버튼 표시) |
| 앱 설치·오프라인 | 자주 쓰는데 매번 주소를 찾아야 하고, 인터넷이 없으면 못 쓴다 | 웹 앱 매니페스트 + 서비스 워커 |

PDF 문서 직접 편집은 PDF 해석 라이브러리(수 MB)가 필요해 이번 범위에서 뺐습니다. PDF는 이미지로 저장해 올리도록 안내합니다.

## 15. 서명 형태 (signature-styles.js)

형태 하나는 `글꼴 + 꾸밈 + 배치 옵션` 조합입니다.

| 속성 | 의미 |
| --- | --- |
| `deco` | swoosh 흘림 밑줄, double 이중 밑줄, wave 물결 밑줄, tail 꼬리 획, circle 동그라미, box 네모, dot 마침점, loop 고리 밑줄, strike 가로지르기 |
| `slant`, `rotate` | 글자 기울기, 전체 회전 (오른쪽이 올라가는 서명) |
| `initial` | 첫 글자 배율 |
| `spacing` | 글자 간격. 음수면 겹쳐 쓴 흘림체 |
| `vertical` | 세로 서명 (한글) |
| `transform` | `first-initial` → J. Doe, `monogram` → JD |

렌더링 순서:

1. 글자 배치: 간격·첫 글자 강조·세로쓰기가 없으면 문자열을 한 번에 그려 필기체 이음과 자간을 살리고, 있으면 글자마다 그린다.
2. 넉넉한 캔버스 가운데에서 회전 → 기울이기 → 글자 그리기.
3. 꾸밈은 글자 경계 상자 기준으로 그리고, 기울기 때문에 밀린 만큼(`-tan × y`) 위치를 보정한다.
4. 굵기가 바뀌는 선(`taper`)으로 붓으로 그은 느낌을 낸다.
5. 알파값 기준으로 여백을 잘라 돌려준다.

사용자 조정: 기울기(-10~20도, 형태 기본값에 더함), 굵기(0~3, 글자 외곽선과 꾸밈 선 굵기).

| 다각형·기타 5 | 모서리 깎은 사각, 팔각, 육각, 마름모, 테두리 없음 |
| 가로·세로형 3 | 가로형, 음각 가로형, 세로형 |
| 둘레글자·날짜 2 | 둘레글자 원(이름을 원 둘레에, 가운데 '인'·머리글자), 날짜 도장(이름 / 날짜 / 문구) |

모양은 속성 조합으로 정의해 새 모양을 추가하기 쉽게 했습니다.

- `outline`: ellipse, rect, round, chamfer, polygon(변 수, 시작 각도), scallop, none
- `layout`: 한글 배치 (column 세로 한 줄, grid 격자, row 가로 한 줄). 영문은 단어별 줄 배치
- 꾸밈 플래그: `double` 안쪽 보조선, `thick` 굵은 테, `inverted` 음각, `dotted` 점선, `dividers` 칸 나눔선

글자 영역 계산: 사각 계열은 안쪽 전체를 쓰고, 곡선·다각형은 모양을 꼭짓점으로 근사한 뒤 **격자 비율에 맞는 가장 큰 내접 사각형**을 이분 탐색으로 구합니다(`largestRectInPolygon`). 네 꼭짓점이 모두 볼록 다각형 안에 있는지로 판정합니다.

음각: 모양을 잉크로 채운 뒤 글자와 안쪽 보조선을 `destination-out`으로 지워 종이색이 드러나게 합니다. 투명 PNG에서는 글자 부분이 투명해집니다.

효과(모든 모양 공통):

- 인주 질감: 시드 고정 난수로 점과 옅은 얼룩을 지운다 (1판과 같음)
- 잉크 번짐: 캔버스 필터 없이, 원본을 12방향으로 조금씩 옮겨 반투명하게 겹친 뒤 원본을 다시 그린다. Safari처럼 `ctx.filter`가 없는 브라우저에서도 같은 결과가 나온다
- 회전: -20~20도. 회전 후 늘어난 크기의 새 캔버스에 그린다

날짜 도장 옵션: 날짜(기본 오늘), 문구(확인, 결재, 검수, 승인, 접수, 완료, APPROVED, RECEIVED, PAID).

## 17. 사진에서 서명 가져오기 (core/image.js)

1. 사진을 긴 변 1600px 이하로 줄이고 EXIF 회전을 반영한다.
2. **조명 보정**: 사진을 칸(사진 크기의 1/24, 최소 32px)으로 나눠 칸마다 밝은 쪽 상위 10% 값을 종이 밝기로 보고, 칸 사이를 선형 보간한 배경으로 나눈다. 그늘진 종이도 흰색에 가깝게 맞춰진다.
3. **경계값**: 오츠(Otsu) 방법으로 잉크와 종이를 가르는 밝기를 자동으로 정한다. 사용자는 '배경 제거' 슬라이더로 ±60 조정한다.
4. 경계 주변 ±18 구간은 알파를 부드럽게 이어 가장자리가 계단지지 않게 한다.
5. **잡티 제거**: 8방향 연결 덩어리 중 면적이 작은 것(사진 면적의 0.004%, 최소 12px)을 지운다.
6. 잉크가 있는 영역만 잘라 선택한 잉크 색으로 칠한다. '사진 색 그대로'를 켜면 원래 색을 쓴다.

## 18. 문서에 넣기 (doc-composer.js)

- 문서 이미지는 긴 변 4000px까지 원본 해상도를 유지한다.
- 올린 항목의 위치와 크기는 문서 픽셀 좌표로 저장하고, 화면에는 `표시 폭 / 문서 폭` 배율로 그린다. 화면 크기가 바뀌어도 위치가 유지된다.
- 조작: 끌어서 이동, 오른쪽 아래 손잡이로 비율 유지 크기 조절, × 버튼으로 빼기. 키보드는 방향키 이동(Shift는 5배), +/- 크기, Delete 빼기.
- '종이에 스며들게 합성'을 켜면 곱하기(multiply) 합성을 써서 종이 질감과 글씨 위에 자연스럽게 얹힌다.
- 저장: 원본 해상도로 합성하고, 올린 파일이 JPG면 JPG(품질 0.92), 아니면 PNG로 저장한다.

## 19. 보관함 (library.js)

- IndexedDB `super-dojang` / `items`에 `{id, kind, name, label, blob, createdAt}`로 저장한다. localStorage와 달리 이미지 Blob을 그대로 넣을 수 있고 용량 제한이 넉넉하다.
- 다른 곳에 다시 쓰기 좋게 항상 투명 배경, 현재 해상도로 저장한다.
- 최대 60개. 넘으면 오래된 것부터 지운다.

## 20. 전체 ZIP (core/zip.js)

- 압축 없이 묶는(store) ZIP 작성기를 직접 구현했다. PNG는 이미 압축된 형식이라 다시 압축해도 크기가 거의 줄지 않는다.
- 파일 이름에 한글이 들어가므로 UTF-8 플래그(일반 목적 비트 11)를 켠다.
- CRC32는 표준 다항식(0xEDB88320) 표로 계산한다.

## 21. 앱 설치·오프라인 (sw.js, manifest.webmanifest)

- 앱 파일: 네트워크 우선, 실패하면 캐시. 새 버전을 배포하면 바로 반영되고, 오프라인일 때만 캐시를 쓴다.
- 글꼴: 캐시 우선. 한 번 받은 글꼴은 다음부터 바로 쓴다.
- 브라우저가 설치를 제안하면 헤더에 '앱 설치' 버튼을 보여 준다.

## 22. 기타 편의

- 서명 생성과 도장 생성 중 한쪽에 입력한 이름을 다른 탭으로 옮기면 자동으로 채운다.
- 마지막으로 입력한 이름을 localStorage에 기억해 다시 열면 바로 후보를 보여 준다.
- 서명 패드에 기준선과 ✕ 표시를 넣어 서명 위치를 잡기 쉽게 했다(저장 이미지에는 들어가지 않음).
- 알림은 화면 아래 토스트로 띄운다.

## 23. 2판 테스트

- 단위 테스트 21개: 1판 10개 + CRC32 표준값, ZIP을 `unzip`으로 풀어 내용·한글 이름 확인, 다각형 내접 사각형, 오츠 경계값, 잡티 제거, 조명 보정, 그늘진 합성 사진에서 획 위치 추출, 서명 형태·도장 모양 개수와 글꼴 등록 확인
