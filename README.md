# 슈퍼도장

전자서명과 도장 이미지를 만들어 PNG로 바로 내려받는 **웹서비스**입니다. 브라우저에서 주소로 열어 쓰며, 앱 설치나 회원가입이 필요 없습니다.

만드는 모든 이미지는 사용자의 브라우저 안에서 그려지고 서버로 보내지 않습니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| 직접 서명 | 손가락·마우스·펜으로 그리기. 또는 종이에 쓴 서명 사진을 올리면 배경을 지워 투명 서명으로 만들기 |
| 서명 생성 | 이름을 입력하면 한글 24가지, 영문 24가지 서명 형태로 후보를 만듭니다 (흘림 밑줄, 동그라미, 세로 서명, 모노그램 등). 기울기·굵기 조절 |
| 도장 생성 | 이름을 입력하면 도장 28가지로 후보를 만듭니다. '인' 붙이기, 읽는 순서(가로·전통 세로), 인주 질감, 잉크 번짐, 회전, 날짜 도장 문구 |
| 문서에 넣기 | 계약서 같은 문서 이미지(JPG·PNG)를 올리고 서명·도장을 끌어 놓은 뒤 한 장으로 저장 |

공통 저장 기능

- 배경: 투명(기본), 흰색, 미색, 직접 고른 색
- 잉크 색: 서명은 검정·남색·파랑, 도장은 빨강·주홍·검정, 직접 고른 색
- 해상도: 보통, 고해상도
- 후보 카드마다 바로 다운로드, 후보 전체를 ZIP 한 파일로 다운로드
- 클립보드 복사, 공유(지원하는 휴대폰 브라우저에서만 버튼 표시)
- 보관함: 만든 이미지를 이 브라우저에 저장해 두고 다시 내려받거나 문서에 넣기
- 한글·영문은 입력한 이름에서 자동으로 감지하고, 직접 고를 수도 있습니다

### 도장 28가지

| 분류 | 모양 |
| --- | --- |
| 원형 7 | 원형, 이중 원, 굵은 테 원, 음각 원, 점선 원, 꽃테 원, 칸 나눔 원 |
| 타원형 4 | 타원, 이중 타원, 음각 타원, 가로 타원 |
| 사각형 7 | 정사각, 이중 사각, 굵은 테 사각, 음각 사각, 칸 나눔 사각, 둥근 사각, 음각 둥근 사각 |
| 다각형·기타 5 | 모서리 깎은 사각, 팔각, 육각, 마름모, 테두리 없음 |
| 가로·세로형 3 | 가로형, 음각 가로형, 세로형 |
| 둘레글자·날짜 2 | 둘레글자 원, 날짜 도장 (확인·결재·검수·승인·접수·완료·APPROVED 등) |

## 사용 방법

1. **서명·도장 만들기**: '서명 생성' 또는 '도장 생성' 탭에서 이름을 입력하면 후보가 바로 나타납니다. 마음에 드는 카드를 누르면 화면 아래에 다운로드 바가 뜹니다.
2. **직접 그리기**: '직접 서명' 탭에서 서명하고 아래 '저장 옵션'에서 PNG로 내려받습니다. 종이 서명을 쓰려면 '사진에서 가져오기'를 고르고 밝은 곳에서 찍은 사진을 올립니다.
3. **문서에 넣기**: 먼저 서명이나 도장을 만들어 고른 뒤 '문서에 넣기' 탭에서 문서 이미지를 올리고 넣을 항목을 누릅니다. 끌어서 옮기고 오른쪽 아래 손잡이로 크기를 바꾼 뒤 '완성 문서 다운로드'를 누릅니다.

## 주의

- 만든 서명·도장은 **이미지일 뿐**이며 등록된 인감이나 공인 전자서명의 효력이 없습니다.
- 다른 사람 이름으로 도장을 만들거나 문서에 넣으면 사문서 위조가 될 수 있습니다.
- 글꼴은 Google Fonts에서 받습니다. 입력한 이름은 보내지 않지만, 글꼴 파일을 받는 과정에서 접속 정보(IP 등)가 Google에 전달됩니다.
- 보관함과 마지막으로 입력한 이름은 이 브라우저에만 저장됩니다. 여러 사람이 쓰는 컴퓨터라면 다 쓴 뒤 보관함의 '모두 지우기'를 눌러 주세요.

## 알려진 제한

- PDF 문서는 직접 올릴 수 없습니다. 화면 캡처나 이미지로 저장해서 올려 주세요.
- 문서 이미지는 긴 변 4000px까지 원본 해상도를 유지하고, 그보다 크면 줄여서 저장합니다. 5천만 화소를 넘는 이미지는 받지 않습니다.
- iPhone Safari는 7일 동안 방문하지 않은 사이트의 저장 데이터를 지울 수 있어, 보관함 항목이 사라질 수 있습니다. 오래 쓸 이미지는 PNG로 내려받아 두세요.
- 클립보드 복사는 HTTPS 주소에서만 동작합니다.
- 브라우저 테스트는 Chromium으로만 했습니다. Safari 관련 처리(복사, 공유, 캔버스 크기 한도)는 알려진 동작에 맞춰 구현했지만 실제 Safari에서는 확인하지 못했습니다.

## 실행

빌드 과정이나 설치할 패키지가 없습니다. ES 모듈을 쓰므로 파일을 직접 열지 말고 HTTP(S)로 서비스해야 합니다.

```bash
npm start          # http://localhost:8080 (Node.js 18 이상)
```

개발용 서버(`scripts/serve.mjs`)는 기본으로 `127.0.0.1`에서만 받습니다. 같은 네트워크의 휴대폰에서 확인하려면 `SERVE_HOST=0.0.0.0 npm start`로 실행하세요.

## 배포

저장소 폴더를 그대로 정적 호스팅(GitHub Pages, Netlify, S3 등)에 올리면 됩니다. GitHub Pages라면 저장소 Settings → Pages에서 배포 브랜치(`main`)와 루트 폴더(`/`)를 고르면 됩니다.

## 개발

```bash
npm test                     # 단위 테스트 24개 (Node 내장 테스트 러너)
npm run e2e                  # 브라우저 흐름 테스트 26항목 (Playwright 필요)
node scripts/fonts-link.mjs  # js/fonts.js 글꼴 목록을 바꾼 뒤 index.html 글꼴 링크 갱신
```

```
index.html               화면
css/style.css            스타일
js/app.js                탭, 상태, 이벤트 연결
js/fonts.js              글꼴 목록과 로더 (Google Fonts)
js/signature-styles.js   서명 형태 48가지 정의
js/signature-gen.js      이름 → 서명
js/signature-pad.js      직접 서명 패드
js/stamp-gen.js          이름 → 도장 28가지
js/photo-import.js       서명 사진 → 투명 서명
js/doc-composer.js       문서에 서명·도장 넣기
js/library.js            보관함 (IndexedDB)
js/exporter.js           여백 자르기, 배경 합성, PNG 저장·복사
js/core/                 DOM 없는 순수 함수 (언어 감지, 배치 계산, 이미지 처리, ZIP, 시드 난수)
tests/                   단위 테스트
scripts/                 개발 서버, 브라우저 테스트, 글꼴 링크 생성
docs/DESIGN.md           설계 문서 (1·2판 설계, 비판적 검토 2회 결과)
```

글꼴은 모두 Google Fonts에서 SIL Open Font License로 배포하는 글꼴입니다.
