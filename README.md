# 슈퍼도장

전자서명과 도장 이미지를 만들어 PNG로 바로 내려받는 **웹서비스**입니다. 브라우저에서 주소로 열어 쓰며, 앱 설치나 회원가입이 필요 없습니다.

웹사이트에서 만드는 모든 이미지는 사용자의 브라우저 안에서 그려지고 서버로 보내지 않습니다.

Claude 같은 AI 도구에서 쓸 수 있는 **MCP 서버**도 있습니다. 아래 [MCP](#mcp) 항목을 보세요.

## 기능

| 탭 | 내용 |
| --- | --- |
| 직접 서명 | 손가락·마우스·펜으로 그리기. 또는 종이에 쓴 서명 사진을 올리면 배경을 지워 투명 서명으로 만들기 |
| 서명 생성 | 이름을 입력하면 한글 24가지, 영문 24가지 서명 형태로 후보를 만듭니다 (흘림 밑줄, 동그라미, 세로 서명, 모노그램 등). 기울기·굵기 조절 |
| 도장 생성 | 이름을 입력하면 도장 105가지로 후보를 만듭니다. '인' 붙이기, 읽는 순서(가로·전통 세로), 인주 질감, 잉크 번짐, 회전, 날짜 도장 문구 |
| 문서에 넣기 | 계약서 같은 문서 이미지(JPG·PNG)를 올리고 서명·도장을 끌어 놓은 뒤 한 장으로 저장 |

공통 저장 기능

- 배경: 투명(기본), 흰색, 미색, 직접 고른 색
- 잉크 색: 서명은 검정·남색·파랑, 도장은 빨강·주홍·검정, 직접 고른 색
- 해상도: 보통, 고해상도
- 후보 카드마다 바로 다운로드, 후보 전체를 ZIP 한 파일로 다운로드
- 클립보드 복사, 공유(지원하는 휴대폰 브라우저에서만 버튼 표시)
- 보관함: 만든 이미지를 이 브라우저에 저장해 두고 다시 내려받거나 문서에 넣기
- 한글·영문은 입력한 이름에서 자동으로 감지하고, 직접 고를 수도 있습니다

인장체 25가지 중 인감체 2가지를 뺀 나머지는 글꼴을 쓰지 않고 한글을 자모로 나눠 직선 획으로 직접 그립니다(`js/core/seal-glyph.js`). 무료로 쓸 수 있는 인장체 글꼴이 없어서입니다. 한글 11,172자와 영문 대문자·숫자를 그릴 수 있습니다. 구첩·삼첩은 긴 획을 접어 빈칸을 메운 모양입니다. 백문은 흰 글자, 주백상간은 칸마다 흰 글자와 붉은 글자를 번갈아 씁니다. 인상체는 글자가 테와 이웃 글자에 맞붙고, 방사는 글자 머리가 테를 향합니다. 둥근 인장체(1·2·3단)는 참고한 인감 도장처럼 획이 가늘고 꺾임과 끝이 둥급니다. 인감체는 손글씨 느낌의 가는 웹 글꼴(하이멜로디)을 칸에 꽉 차게 늘려 씁니다. 두 가지 모두 유료 인장체 글꼴을 쓸 수 없어 비슷하게 직접 만든 것입니다.

둘레글자 31가지는 둘레에 이름을 두르는 직인 형식입니다. 테 모양(둥근 사각·육각·팔각·톱니)과 꾸밈(별 양옆선·점선·음각·별띠)도 고를 수 있습니다. 인장체 직인·삼첩 직인·구첩 직인은 둘레 글자도 둥근 인장체로, 인감체 직인은 인감체 글꼴로 그립니다. 법인 직인, 중국식 공장(별), 서양식 법인 인장, 타원 직인, 음각 띠 등이 있습니다. 가운데에는 세부 옵션 '직인 가운데'에서 고른 글자를 넣습니다(공장 별은 가운데가 늘 별). 고를 수 있는 글자는 代表理事(기본), 대표이사, 대표이사인, 직인, 印, 이름, ★입니다. 한자는 고른 글꼴과 상관없이 본명조로(인감체 직인은 가는 본명조 500), 오른쪽 열부터 세로로 씁니다. 한글과 이름은 '읽는 순서'를 따릅니다. 영문 이름은 머리글자를 넣습니다.

날짜·결재 도장의 문구는 확인·결재·검수·승인·접수·완료·APPROVED·RECEIVED·PAID 중에서 고릅니다. 고르지 않으면 모양에 맞는 문구가 들어갑니다(날짜 도장 '확인', 접수인 '접수', 결재 칸 '결재').

한글 도장 글꼴은 16가지입니다. 나눔명조, 본명조, 송명, 검은고딕, 고운바탕, 도현, 함렛, 주아, 구기, 나눔손글씨 붓, 고딕 A1, 해바라기, 가석, 베이글, 아스타, 흑백사진. 송명·검은고딕·도현·함렛·주아·구기·해바라기·가석·베이글은 자주 쓰는 한글 2,350자만 들어 있어, 드문 글자(예: 똠, 쭝)는 그 글자만 다른 글꼴로 그려집니다.

## 사용 방법

1. **서명·도장 만들기**: '서명 생성' 또는 '도장 생성' 탭에서 이름을 입력하면 후보가 바로 나타납니다. 마음에 드는 카드를 누르면 화면 아래에 다운로드 바가 뜹니다.
2. **직접 그리기**: '직접 서명' 탭에서 서명하고 아래 '저장 옵션'에서 PNG로 내려받습니다. 종이 서명을 쓰려면 '사진에서 가져오기'를 고르고 밝은 곳에서 찍은 사진을 올립니다.
3. **문서에 넣기**: 먼저 서명이나 도장을 만들어 고른 뒤 '문서에 넣기' 탭에서 문서 이미지를 올리고 넣을 항목을 누릅니다. 끌어서 옮기고 오른쪽 아래 손잡이로 크기를 바꾼 뒤 '완성 문서 다운로드'를 누릅니다.

## 주의

- 만든 서명·도장은 **이미지일 뿐**이며 등록된 인감이나 공인 전자서명의 효력이 없습니다.
- 다른 사람 이름으로 도장을 만들거나 문서에 넣으면 사문서 위조가 될 수 있습니다.
- 글꼴은 Google Fonts에서 받습니다. 입력한 이름은 보내지 않지만, 글꼴 파일을 받는 과정에서 접속 정보(IP 등)가 Google에 전달됩니다.
- 보관함과 마지막으로 입력한 이름은 이 브라우저에만 저장됩니다. 여러 사람이 쓰는 컴퓨터라면 다 쓴 뒤 보관함의 '모두 지우기'를 눌러 주세요.

## 알려진 제한

- PDF 문서는 직접 올릴 수 없습니다. 화면 캡처나 이미지로 저장해서 올려 주세요.
- 문서 이미지는 긴 변 4000px까지 원본 해상도를 유지하고, 그보다 크면 줄여서 저장합니다. 5천만 화소를 넘는 이미지는 받지 않습니다.
- iPhone Safari는 7일 동안 방문하지 않은 사이트의 저장 데이터를 지울 수 있어, 보관함 항목이 사라질 수 있습니다. 오래 쓸 이미지는 PNG로 내려받아 두세요.
- 클립보드 복사는 HTTPS 주소에서만 동작합니다.
- 브라우저 테스트는 Chromium으로만 했습니다. Safari 관련 처리(복사, 공유, 캔버스 크기 한도)는 알려진 동작에 맞춰 구현했지만 실제 Safari에서는 확인하지 못했습니다.

## 실행

빌드 과정이나 설치할 패키지가 없습니다(MCP 서버만 `mcp/`에서 따로 설치합니다). ES 모듈을 쓰므로 파일을 직접 열지 말고 HTTP(S)로 서비스해야 합니다.

```bash
npm start          # http://localhost:8080 (Node.js 18 이상)
```

개발용 서버(`scripts/serve.mjs`)는 모든 파일에 `Cache-Control: no-cache`와 내용 기준 `ETag`를 붙입니다. 고친 파일은 바로 반영되고, 바뀌지 않은 파일은 304로 응답해 다시 내려받지 않습니다. 기본으로 `127.0.0.1`에서만 받습니다. 같은 네트워크의 휴대폰에서 확인하려면 `SERVE_HOST=0.0.0.0 npm start`로 실행하세요.

## 배포

저장소 폴더를 그대로 정적 호스팅(GitHub Pages, Netlify, S3 등)에 올리면 됩니다. GitHub Pages라면 저장소 Settings → Pages에서 배포 브랜치(`main`)와 루트 폴더(`/`)를 고르면 됩니다.

## MCP

AI 도구가 슈퍼도장 기능을 직접 쓰게 하는 MCP 서버입니다(`mcp/` 폴더). 사이트와 같은 코드를 헤드리스 Chrome에서 실행해 그리므로 결과도 사이트와 똑같습니다.

### 연결

| 방식 | 주소·명령 | 결과 파일 | 입력 이미지 |
| --- | --- | --- | --- |
| 원격 | `https://dojangfree.jihyeadminoffice.com/mcp` | 1시간 동안 받을 수 있는 다운로드 링크 | 업로드 링크, 공개 https 주소, base64 |
| 로컬 | `node mcp/server.mjs` (stdio) | `~/Downloads/슈퍼도장`에 저장 | 파일 경로, 공개 https 주소, base64 |

```bash
# 원격 (Claude Code). claude.ai에서는 설정 → 커넥터 → 사용자 지정 커넥터에 같은 주소를 넣습니다
claude mcp add --transport http super-dojang https://dojangfree.jihyeadminoffice.com/mcp

# 로컬: Google Chrome이 설치되어 있어야 합니다
cd mcp && npm install
claude mcp add super-dojang -- node "$PWD/server.mjs"
```

원격 서버는 인증 없이 누구나 쓸 수 있습니다. 대신 접속 주소(IP)마다 요청 수를 제한합니다(순간 60회, 이후 10초에 1회). 원격 서버를 직접 띄울 때는 `DOJANG_PUBLIC_URL=https://내도메인 node mcp/server.mjs --http 7550`처럼 실행합니다. 서버는 `127.0.0.1`에서만 받으므로 앞에 HTTPS 프록시나 터널을 두어야 합니다.

### 개인정보

- 로컬: 이름과 이미지가 이 컴퓨터 밖으로 나가지 않습니다. 글꼴 파일만 Google Fonts에서 받습니다.
- 원격: 입력한 이름과 올린 사진·문서가 서버로 전송되어 처리됩니다. 결과 파일과 올린 파일은 메모리에만 두고 1시간 뒤 지웁니다. 로그에는 도구 이름과 처리 시간만 남기고, 이름이나 이미지는 남기지 않습니다.
